# Xiaomi Pad 5: Arch Linux ARM + Hyprland + Serpantinum

Цільовий пристрій: **Xiaomi Pad 5, nabu**, не Pad 5 Pro і не Pad 6.
Це експериментальний варіант upstream Nabu-arch-images. Успішна збірка та програмні тести не замінюють перевірку на самому планшеті. Статус конкретної збірки дивись у GitHub Actions.

## Що всередині

- Ядро й прошивки, звук, Wi-Fi, Bluetooth, UKI/rEFInd і recovery-інсталятор з Nabu-arch-images.
- Hyprland 0.57.0 та відповідний за API Hyprgrass, зібраний для ARM64.
- Serpantinum із закріпленого коміту, а не x86_64-пакет AUR. Ski, serpantinum-audio, wvkbd та wl-gammarelay-rs збираються з джерел на ARM64.
- Масштаб 1.6, збільшені панель і dock, UA/RU/US розкладки, українська локалізація оболонки.
- Екранна клавіатура Squeekboard у програмах; окрема клавіатура **всередині захищеної поверхні блокування**, для паролів із латиницею, цифрами та символами.
- Поворот зображення разом із координатами тача. Поворот ручний; автоматичний поворот акселерометром у цій версії не налаштовано.

У верхній панелі **UA → RU → US** перемикає мову також на екранній клавіатурі, **⌨** відкриває/ховає її, **↻** повертає зображення й координати тача. Поворот зберігається після перезапуску. Шпалери вже є у `~/Pictures/Wallpapers`.

Кнопка живлення переводить систему в сон; тривале натискання вимикає. Розблокування — через штатну автентифікацію PAM. На екрані блокування введи пароль нижньою клавіатурою та натисни Unlock. Shift змінює регістр, #+= відкриває символи, Clear очищає поле.

Жести прокручування й pinch-to-zoom усередині програм залежать від підтримки тача самою програмою. Параметри та жести Hyprgrass потребують перевірки фізичними пальцями на Pad 5. Перший запуск варто виконувати з доступною USB-клавіатурою для відновлення, якщо плагін не працюватиме.

## Отримання інсталятора

На сторінці [Actions](https://github.com/hxfuxyy/Nabu-arch-images/actions/workflows/build-installers.yml) відкрий **успішний** запуск актуального коміту гілки `hyprland-touch`. Завантаж artifact `arch-nabu-installer-hyprland`.

GitHub видає зовнішній ZIP-архів artifact. **Розпакуй його на ПК.** Усередині будуть:

- `arch-nabu-installer-hyprland.zip` — саме цей внутрішній ZIP прошивається через TWRP;
- `arch-nabu-installer-hyprland.zip.sha256` — контрольна сума.

У Linux у папці з цими двома файлами:

```bash
sha256sum -c arch-nabu-installer-hyprland.zip.sha256
unzip -t arch-nabu-installer-hyprland.zip
```

У Windows PowerShell:

```powershell
Get-FileHash .\arch-nabu-installer-hyprland.zip -Algorithm SHA256
Get-Content .\arch-nabu-installer-hyprland.zip.sha256
```

Хеші мають збігатися. SHA256 перевіряє цілісність отриманого файлу; це не незалежний підпис походження. Файл `BUILD-SOURCES.json` усередині ZIP містить закріплені коміти компонентів.

## Встановлення, коли зараз є лише Android-розділи

Перерозмітка може стерти Android-дані; користувач погодився, що збереження даних не потрібне. Не стирай навмання службові розділи, modem/persist або таблицю розділів. Інсталятор сам не створює linux/esp.

1. Потрібен **розблокований bootloader** і ПК з Android platform-tools (`adb`, `fastboot`). Якщо bootloader ще заблокований — спочатку розблокуй штатним способом для свого облікового запису Xiaomi. Не блокуй його назад із цим Linux.
2. Завантаж recovery **Hybrid TWRP саме для nabu** зі [сторінки автора](https://github.com/Kumar-Jy/twrp_device_xiaomi_nabu/releases/tag/mod-hybrid). Назви завантажений файл `hybrid-twrp.img` або вкажи його справжню назву в команді.
3. Вимкни планшет. Power + Volume Down відкриває fastboot. На ПК:

   ```bash
   fastboot devices
   fastboot getvar product
   fastboot boot hybrid-twrp.img
   ```

   Перевір, що product — `nabu`. Команда `boot` тимчасово запускає recovery; не підміняй її неперевіреними командами flash.
4. У TWRP: **Advanced → Terminal**, команда:

   ```sh
   partition
   ```

   Створи розділи **linux** та **esp** засобом із цього recovery. Windows-розділ не потрібен. Для linux рекомендовано від 32 ГіБ для системи, збірок і програм; фактичний rootfs образ має вміщатися в нього. Якщо майстер запитує розміри чи збереження Android, обирай відповідно до потрібного місця. Не використовуй випадкові готові номери секторів з іншого планшета.
5. Після перерозмітки: **Reboot → Recovery**. Повторно перевір наявність розділів:

   ```sh
   ls -l /dev/block/by-name/linux /dev/block/by-name/esp
   blockdev --getsize64 /dev/block/by-name/linux
   ```

6. Скопіюй **внутрішній** `arch-nabu-installer-hyprland.zip` у пам'ять планшета після перерозмітки (MTP або `adb push arch-nabu-installer-hyprland.zip /sdcard/`). Якщо `/sdcard` недоступна — скористайся USB-OTG або **Advanced → ADB Sideload** і на ПК:

   ```bash
   adb sideload arch-nabu-installer-hyprland.zip
   ```

7. Через **Install** вибери інсталяційний ZIP та проший (або дочекайся sideload). Скрипт перевіряє модель і розмір linux перед форматуванням, записує rootfs у linux, налаштовує ESP і патчить boot через upstream DBKP. **Наявний вміст linux буде стерто.** Не переривай живлення.
8. Після успішного завершення: **Reboot → System**, у rEFInd вибери Arch Linux. Перший запуск може бути довшим через налаштування системи.
9. Початковий обліковий запис: **`user`**, пароль **`123456`**. Вхід автоматичний, як в upstream. Відкрий Kitty через меню програм, покажи клавіатуру жестом і зміни пароль:

   ```bash
   passwd
   ```

   Клавіатура блокування цієї версії має латиницю, цифри й символи; для першого тесту обери пароль із цих знаків. Перевір введення та розблокування перед використанням сну. Не забудь, що автоматичний вхід після перезапуску залишається увімкненим у `/etc/sddm.conf.d/10-nabu-hyprland.conf`.

## Перевірка після запуску

Перевір послідовно: натискання в кутах екрана, прокручування Firefox, клавіатуру, кожен жест із таблиці, поворот та координати тача після кожного з чотирьох поворотів, підключення Wi-Fi, гучність, блокування/розблокування новим паролем, сон та пробудження.

Діагностика з термінала:

```bash
hyprctl configerrors
hyprctl plugin list
hyprctl devices
serpantinumd status
wpctl status
journalctl -b -p warning
```

У `plugin list` має бути Hyprgrass. Якщо жестів немає — це не доводить, що не працює драйвер тача: перевір спочатку звичайні натискання та наявність плагіна.

## Оновлення і відновлення

`hyprland` закріплений через IgnorePkg, бо Hyprgrass залежить від його API; ядро закріплене upstream. Для оновлення Hyprland потрібен відповідний коміт Hyprgrass і повторна збірка. Не прибирай це закріплення без такої перевірки. Установка Serpantinum через upstream curl-інсталятор поверх цього образу не підтримується: він має x86_64-завантаження. Решту системи оновлюй `sudo pacman -Syu`.

Якщо графічний сеанс не працює, підключи USB-клавіатуру, перейди Ctrl+Alt+F3, увійди як user і перевір журнал. Для тимчасового вимкнення плагіна прибери `hl.plugin.load(...)` з `~/.config/hypr/hyprland.lua`; звичайний тач і dock мають залишитися доступними, але жести плагіна зникнуть. Якщо система не завантажується, користуйся [upstream Troubleshooting](https://github.com/Kumar-Jy/Nabu-arch-images/blob/non-atomic-7.3.y/TROUBLESHOOTING.md) через recovery.
